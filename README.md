# 🎬 영화 예매 관리 시스템 (Movie Reservation System)

> **Java Collection Framework(ArrayList, HashMap)를 활용한 객체 지향 기반의 영화 예매 및 매출 관리 프로그램**

본 프로젝트는 영화관의 영화 목록 관리, 회원 등록, 예매 프로세스 및 이에 따른 매출 통계를 효율적으로 처리하기 위해 설계되었습니다. 패키지 세분화를 통해 높은 유지보수성과 객체 지향 원칙을 준수하도록 개발되었습니다.

## 📊 2. 핵심 기능 및 자료구조 활용 이유

각 데이터의 특성과 처리 목적에 알맞은 **Collection Framework**를 선택하여 프로그램의 데이터 처리 효율성을 극대화했습니다.

* **🔹 ArrayList 활용**
  * **대상 기능:** 영화 목록 저장 (`ArrayList<Movie>`), 회원 목록 저장 (`ArrayList<Member>`)
  * **이유:** 등록된 순서대로 데이터를 유지하고, 인덱스를 바탕으로 전체 목록을 처음부터 끝까지 화면에 **순차적으로 출력(조회)**하는 데 가장 적합한 구조이기 때문입니다.

* **🔹 HashMap<K, V> 활용**
  * **대상 기능:** 영화 검색 (`HashMap<String, Movie>`), 회원 검색 (`HashMap<String, Member>`)
  * **이유:** 영화 제목이나 회원 ID 같은 고유한 키(Key) 값을 사용하여 전체 리스트를 다 뒤지지 않고도 **$O(1)$의 빠른 속도**로 원하는 데이터(Value)를 즉시 찾아내기 위함입니다.

* **🔹 중첩 구조 (Map + List) 활용**
  * **대상 기능 1: 회원별 예매 내역** (`HashMap<String, ArrayList<Reservation>>`)
    * **이유 (1:N 일대다 관계):** 한 명의 회원(ID)이 여러 개의 영화를 예매할 수 있습니다. 따라서 회원 ID를 Key로 지정하고, 그 회원이 가질 수 있는 여러 개의 예매 객체들을 `ArrayList`로 묶어 Value로 매핑함으로써 체계적인 이력 관리가 가능합니다.
  * **대상 기능 2: 영화별 예매 수** (`HashMap<String, Integer>`)
    * **이유:** 영화 제목을 Key로 두고, 예매가 발생할 때마다 `getOrDefault()` 메서드를 활용하여 누적 인원 수(Value)를 유연하게 합산 및 저장하기 위함입니다.

## 🚀 5. 실행 및 테스트 시나리오

1. **프로그램 시작**
   * `main.Main` 클래스를 실행하여 시스템 콘솔 창을 활성화합니다.

2. **영화 데이터 등록 (메뉴 1번)**
   * `1`을 입력한 뒤, 가이드에 따라 아래 예시 데이터를 등록합니다.
     * **영화 제목 입력:** `범죄도시`
     * **장르 입력:** `액션`
     * **상영 시간 입력:** `19:00`
     * **티켓 가격 입력:** `12000`
   * *※ 등록 후 `2번(영화 전체 조회)`을 눌러 데이터가 누적되었는지 확인합니다.*

3. **회원 데이터 등록 (메뉴 4번)**
   * `4`을 입력한 뒤, 회원 정보를 콘솔에 직접 입력합니다.
     * **회원 ID 입력:** `user01`
     * **이름 입력:** `최인준`
     * **전화번호 입력:** `010-1234-5678`
   * *※ 등록 후 `5번(회원 전체 조회)`을 눌러 회원이 정상 등록되었는지 확인합니다.*

4. **영화 예매 진행 (메뉴 6번)**
   * `6`을 입력하고 앞서 생성한 고유 데이터를 매핑하여 예매를 완료합니다.
     * **회원 ID 입력:** `user01`
     * **영화 제목 입력:** `범죄도시`
     * **예매 인원 입력:** `3`

5. **매출 및 통계 실시간 확인 (메뉴 7, 8, 9번)**
   * **7번 (회원별 내역):** `user01` 입력 시 `범죄도시 / 19:00 / 3명 / 36000원`이 출력되는지 확인합니다.
   * **8번 (영화별 인원):** `범죄도시: 3명`이 정상 누적되었는지 확인합니다.
   * **9번 (총 매출 조회):** 티켓 가격과 인원수가 정상 연산되어 현재 총 매출이 `36000원`으로 합산되었는지 검증합니다.
