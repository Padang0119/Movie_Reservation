# 🎬 영화 예매 관리 시스템 (Movie Reservation System)

> **Java Collection Framework(ArrayList, HashMap)를 활용한 객체 지향 기반의 영화 예매 및 매출 관리 프로그램**

본 프로젝트는 영화관의 영화 목록 관리, 회원 등록, 예매 프로세스 및 이에 따른 매출 통계를 효율적으로 처리하기 위해 설계되었습니다. 패키지 세분화를 통해 높은 유지보수성과 객체 지향 원칙을 준수하도록 개발되었습니다.

---

## 📂 1. 프로젝트 구조 (Project Structure)

```text
src/
 ├─ main/
 │   └─ Main.java              # 프로그램 실행 및 메뉴 인터페이스 제어
 ├─ model/                     # 데이터 클래스 (Value Object)
 │   ├─ Movie.java             # 영화 정보 (제목, 장르, 상영시간, 가격)
 │   ├─ Member.java            # 회원 정보 (ID, 이름, 전화번호)
 │   └─ Reservation.java       # 예매 정보 (영화, 인원, 총 결제금액)
 └─ manager/                   # 핵심 비즈니스 로직 관리 클래스
     ├─ MovieManager.java      # 영화 등록, 전체 조회, 단건 검색
     ├─ MemberManager.java     # 회원 등록, 전체 조회, 회원 검색
     └─ ReservationManager.java # 영화 예매, 회원별 내역 조회, 통계 및 매출 관리

📊 2. 핵심 기능 및 자료구조 활용 이유
각 데이터의 특성과 처리 목적에 알맞은 Collection Framework를 선택하여 프로그램의 데이터 처리 효율성을 극대화했습니다. (★ 발표 및 보고서 핵심 포인트)

🔹 ArrayList 활용
영화 목록 저장 (ArrayList<Movie>) / 회원 목록 저장 (ArrayList<Member>)

이유: 등록된 순서대로 데이터를 유지하고, 인덱스를 바탕으로 전체 목록을 처음부터 끝까지 화면에 순차적으로 출력(조회)하는 데 가장 적합한 구조이기 때문입니다.

🔹 HashMap<K, V> 활용
영화 검색 (HashMap<String, Movie>) / 회원 검색 (HashMap<String, Member>)

이유: 영화 제목이나 회원 ID 같은 고유한 키(Key) 값을 사용하여 전체 리스트를 다 뒤지지 않고도 $O(1)$의 빠른 속도로 원하는 데이터(Value)를 즉시 찾아내기 위함입니다.

🔹 중첩 구조 (Map + List) 활용
회원별 예매 내역 (HashMap<String, ArrayList<Reservation>>)

이유 (1:N 일대다 관계): 한 명의 회원(ID)이 여러 개의 영화를 예매할 수 있습니다. 따라서 회원 ID를 Key로 지정하고, 그 회원이 가질 수 있는 여러 개의 예매 객체들을 ArrayList로 묶어 Value로 매핑함으로써 체계적인 이력 관리가 가능합니다.

영화별 예매 수 (HashMap<String, Integer>)

이유: 영화 제목을 Key로 두고, 예매가 발생할 때마다 getOrDefault() 메서드를 활용하여 누적 인원 수(Value)를 유연하게 합산 및 저장하기 위함입니다.
